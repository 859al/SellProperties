# 🏗️ Property Development Profit Analyzer

> **A proof-of-concept platform for discovering and analysing property development opportunities.**

## 💡 Concept

The website explores the idea of finding properties in poor condition and analysing whether they would be more profitable to **demolish and rebuild** or **refurbish**.

The concept is to estimate:

**Purchase Price → Development Costs → Final Property Value → Potential Profit → ROI**

The current website is a **shell / proof of concept**. It is not fully functional yet and mainly demonstrates the concept, interface, and proposed mechanism.

## ⚙️ Technology

The current concept uses **JavaScript** for the website and proposed calculations.

In the future, it could be connected to **property APIs, market data, construction-cost data, or an AI agent** to make the analysis more advanced and automated.
